# Бот для шагового марафона

Читает скриншоты шагов в групповом чате, распознаёт число через Tesseract OCR,
просит подтверждение у автора и сохраняет результат в Google Таблицу
(дата, участник, шаги, статус, ссылка на сообщение).

## 1. Установка Tesseract (движок OCR)

Это отдельная системная программа, не Python-библиотека.

**Raspberry Pi / Ubuntu / Debian:**
```bash
sudo apt update
sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng -y
```

**macOS:**
```bash
brew install tesseract tesseract-lang
```

**Windows:**
Скачать установщик: https://github.com/UB-Mannheim/tesseract/wiki
При установке отметить русский языковой пакет.

Проверить, что всё установилось:
```bash
tesseract --version
```

## 2. Создание Telegram-бота

1. В Telegram напиши **@BotFather** → `/newbot` → следуй инструкциям, получишь `BOT_TOKEN`.
2. Обязательно отключи Privacy Mode, иначе бот не будет видеть чужие сообщения в группе:
   `@BotFather` → `/mybots` → выбери бота → `Bot Settings` → `Group Privacy` → `Turn off`.
3. Добавь бота в свой групповой чат марафона.

## 3. Настройка Google Sheets

1. Зайди в [Google Cloud Console](https://console.cloud.google.com/), создай проект.
2. Включи API: **Google Sheets API** и **Google Drive API**.
3. Создай сервисный аккаунт: `IAM & Admin → Service Accounts → Create Service Account`.
4. Создай для него JSON-ключ (`Keys → Add Key → JSON`), скачай файл и положи
   его в папку проекта как `credentials.json`.
5. Открой JSON-файл, скопируй поле `client_email` (выглядит как
   `xxx@xxx.iam.gserviceaccount.com`).
6. Создай пустую Google Таблицу, открой доступ на редактирование
   для этого email (кнопка "Настройки доступа" → вставить email → "Редактор").
7. Скопируй ID таблицы из URL:
   `https://docs.google.com/spreadsheets/d/ЭТОТ_ID/edit`

## 4. Установка проекта (Raspberry Pi / любой Linux)

```bash
# скопируй папку steps_bot на устройство, затем:
cd steps_bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
nano .env   # впиши BOT_TOKEN и SPREADSHEET_ID
# положи credentials.json в эту же папку
```

Проверка вручную (бот должен запуститься без ошибок):
```bash
python bot_old.py
```
Пришли фото в чат — если всё настроено верно, бот ответит с распознанным числом.
Останови проверку через Ctrl+C.

## 5. Автозапуск через systemd (чтобы бот работал постоянно, включая перезагрузки)

Отредактируй `stepbot.service`: замени `pi` на своего пользователя и путь
`/home/pi/steps_bot` на реальный путь к проекту (посмотреть можно командой `pwd`
находясь в папке проекта). Обрати внимание: `ExecStart` указывает на
`venv/bin/python` — так сервис будет использовать нужное окружение с
установленными библиотеками.

```bash
sudo cp stepbot.service /etc/systemd/system/stepbot.service
sudo systemctl daemon-reload
sudo systemctl enable stepbot
sudo systemctl start stepbot
```

Проверить статус и логи:
```bash
sudo systemctl status stepbot
journalctl -u stepbot -f
```

Теперь бот будет:
- запускаться автоматически при включении Raspberry Pi;
- перезапускаться сам, если упадёт с ошибкой (`Restart=always`).

## 6. Как это работает в чате

1. Участник присылает скриншот шагов.
2. Бот отвечает распознанным числом с кнопками **✅ Верно** / **✏️ Исправить**.
3. Если число неверное — участник жмёт "Исправить" и присылает правильное
   число текстом.
4. Если за сегодня для этого участника уже есть запись, бот предупредит
   и подтверждение перезапишет её (защита от случайных дублей).
5. Команда `/today` в чате покажет текущий рейтинг за сегодня.

В таблице у каждой строки есть колонка "Статус" (`confirmed` — подтверждено
кнопкой, `manual` — введено вручную) и ссылка на исходное сообщение —
это пригодится, если возникнут споры о честности результата.

## Важные ограничения и что стоит знать

- **Точность OCR**: Tesseract — бесплатный движок, но менее точный, чем
  платные API (Google Vision, Claude API и т.п.), особенно на скриншотах
  из разных приложений с разным дизайном. Поэтому в боте реализовано
  обязательное подтверждение числа человеком — не полагайтесь на
  автоматическое распознавание как на финальный результат без проверки.
- **Privacy Mode должен быть выключен** (шаг 2) — иначе бот вообще не
  увидит сообщения от других участников, только команды, адресованные ему.
- **Античит**: этот бот не проверяет, что скриншот подлинный (не
  редактирован, не переслан с чужого телефона и т.п.) — только
  автоматизирует ввод чисел. Если для приза важна защита от накруток,
  дополнительно стоит вручную выборочно сверять скриншоты у лидеров.
- Раз в 1-2 месяца заходите проверить, что Tesseract не хуже стал
  справляться с новыми версиями приложений (интерфейсы обновляются).
